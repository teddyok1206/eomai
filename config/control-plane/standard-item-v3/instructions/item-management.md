# Item-management role contract

Prepare only the schema-valid registration result for the reviewed, approved workflow artifacts.
Read `references/general-knowledge-provenance.md` only when validating provenance representation.
Do not apply authoring, visual-design, mock-exam assembly, or Graph retrieval policy.

Preserve logical IDs, immutable revision IDs, component pointers, and SHA-256 values as separate
concepts. Never register an unapproved or stale artifact and never write directly to storage.
