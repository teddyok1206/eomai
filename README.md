# EOM Scientific Studio

**과학 문항의 제작·검토·관리를 하나의 작업 공간에서.**

교과서와 기출 근거를 활용한 출제부터 문항 검색, 교재 편성, 편집 가능한 HWPX 출력까지 연결합니다.
문항을 만드는 사람과 검토·편집하는 사람이 같은 자료와 이력을 확인하며 작업할 수 있습니다.

[문서 안내](docs/README.md) · [시스템 구조](docs/architecture/MODULE_BOUNDARIES.md) · [운영 기록](docs/operations/)

## 할 수 있는 일

| 기능 | 주요 작업 |
| --- | --- |
| 문항 제작·기출변형 | 단원·난이도·자연어 요구로 출제하고, 자동 검토와 최대 3차 피드백으로 다듬습니다. |
| 자료 검토 | PDF·HWP·HWPX와 별도 해설지를 검토하고, 지적 위치를 표시한 주석 PDF를 내려받습니다. |
| 문항 DB·유사도 | 기출·창작·외부·AI 문항을 조건별로 찾고, 풀이와 근거가 관련된 문항을 비교합니다. |
| Excel 콘텐츠 편성 | 교재·시험지의 판·회차에 문항을 배치하고, 재사용·변경·인쇄 이력을 관리합니다. |
| HWPX 출력 | 선택 문항이나 편성한 회차를 표·수식·그림이 포함된 편집 가능한 한글 문서로 만듭니다. |
| 자료 학습·Map | 업로드한 자료의 설명·문항·풀이를 구조화하고, 출처와 개념의 Graph 연결을 탐색합니다. |
| 내부 자료 대화 | ChatGPT 화면에서 대화하며, 접근 권한이 있는 내부 자료를 검색하고 참고합니다. |

관리자는 계정·역할·작업 슬롯·실행 설정을 관리합니다. 문항의 등록 상태와 사람의 승인 여부는 구분해 표시합니다.

## 작업 흐름

- **새 문항:** 출제 요청 → 자동 검토·피드백 → DB 등록 → HWPX 확인 → 사람 승인
- **기존 자료:** 파일 업로드 → 자료 분석·등록 → DB 검색·유사 문항 비교
- **교재·시험지:** 문항 선택 → Excel 편성 → HWPX 출력 → 인쇄·사용 이력 관리

문항 등록과 HWPX 제작은 최종 승인 전에도 진행할 수 있습니다.
자동 검토가 사람의 최종 판단을 대신하지 않으며, 유사도 점수도 표절 여부나 풀이가 같을 확률을 뜻하지 않습니다.

## 근거와 데이터

GraphRAG는 **출처·개념의 관계**, 로컬 임베딩은 **관련 문항 탐색**을 담당합니다.
문항·풀이보고서·원문은 정확한 버전과 참조로 연결하고, 접근 권한과 파일 무결성을 확인합니다.

자료 학습은 업로드한 내용을 검색 가능한 지식으로 구조화하는 과정입니다.
언어 모델 작업은 격리된 Codex 슬롯에서, 이미지·임베딩 계산은 로컬 모델로 실행합니다.
원본 자료와 생성 결과는 Git에 넣지 않습니다.

## 사용 및 개발

사용자는 운영자가 제공한 Scientific Studio 주소에 관리자 발급 계정으로 로그인합니다.
별도 설치·개발에는 PostgreSQL, 파일 저장소, 격리 실행환경과 구성요소별 배포가 필요합니다.
저장소를 복제하는 것만으로 운영 서비스가 시작되지는 않습니다.

- [개발 규칙](AGENTS.md): 책임 경계, 계약, 테스트와 보안 원칙
- [코드 탐색 지도](docs/agent-context/README.md): 작업별 담당 모듈과 테스트
- [상세 상태표 보존본](docs/status/README_CHECKPOINT_2026-11-10.md): 이전 README의 버전·검증 이력

운영 반영 여부는 각 릴리스 기록을 기준으로 확인합니다.
소스 테스트 통과와 실제 사용자 검증, 문항의 교육적 품질은 별도로 관리합니다.
