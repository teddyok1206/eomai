# 문항 핵심 착상의 전이 가능성 설계 원문

맞아. 그건 **‘풀이 작업의 종류’**를 분류한 것이지, 문제를 풀면서 느끼는 닮은점을 잡기에는 너무 넓어.

우리가 찾아야 하는 것은 **“이 문제를 풀리게 만드는 핵심 착상이 다른 문제에서도 통하는가?”**에 더 가까워.

### 1. 풀이 순서보다 ‘조건의 역할과 결정적 추론’을 비교해야 해

다음 네 가지를 구체적으로 기록하는 게 좋겠어.

- **무엇이 직접 주어지고, 무엇을 숨겨놓았는가?**
- **어떤 조건들을 연결해야 숨겨진 관계가 드러나는가?**
- **그 관계를 알아내면 어떤 판단이 가능해지는가?**
- **어떤 잘못된 생각을 하면 오답에 도달하는가?**

“보존 법칙을 적용했다”에서도 멈추면 안 돼. **어떤 계에서, 어떤 조건 때문에 보존되며, 그 보존 관계로 무엇을 역으로 알아냈는지**까지 내려가야 해.

### 2. 예를 들면 이런 차이야

실제 기출이 아닌 설명용 예로:

| 문제 | 풀리는 핵심 |
|---|---|
| 병렬로 연결된 두 용수철에 힘이 어떻게 분배되는가 | 변형량이 같다는 조건과 전체 힘의 합을 연결 |
| 병렬 저항에 전류가 어떻게 분배되는가 | 전압이 같다는 조건과 전체 전류의 합을 연결 |
| 직렬로 연결된 두 용수철의 변형량은 얼마인가 | 힘이 같다는 조건과 전체 변형량의 합을 연결 |

첫째와 둘째는 소재와 공식이 다르지만, **“공통으로 유지되는 숨은 변수를 찾아 총량을 분배한다”**는 착상이 대응돼.

반면 첫째와 셋째는 둘 다 용수철·훅의 법칙 문제인데, **무엇이 같고 무엇을 합쳐야 하는지**가 달라.

다만 첫째와 둘째의 관계는 *구조적 유사성*이지, 학생이 반드시 같은 유형으로 느낀다는 뜻은 아니야. 따라서 개념·소재·핵심 착상의 유사성을 따로 보여줘야 해. 관계의 대응을 중시하는 접근은 [구조 대응 이론](https://groups.psych.northwestern.edu/gentner/papers/Gentner83.2b.pdf)과도 연결돼.

### 3. EOM에서는 ‘후보 검색’과 ‘닮은 이유 확인’을 나누자

로컬 임베딩에는 기존 풀이보고서에서 **핵심 조건, 중간에 알아내야 하는 관계, 결정적 추론, 오개념**을 추린 표현을 넣는 게 좋겠어. 원래 보고서는 그대로 보존하고, 이것을 별도의 비교용 표현으로 만드는 거야.

그다음 가까운 후보 몇 개에 대해서만 Codex가 기존 Graph·근거를 읽고 다음을 비교하도록 하면 돼.

- A의 어떤 조건이 B의 어떤 조건에 대응하는가?
- A의 핵심 착상을 B에 실제로 적용할 수 있는가?
- 대응되지 않는 부분과 새로 필요한 추론은 무엇인가?
- 숫자·이름만 바뀐 것인가, 출제 의도가 연결된 새로운 문제인가?

즉 **“비슷합니다, 점수 0.87”이 아니라 “이 조건들의 연결과 이 추론이 같고, 이 부분은 달라졌습니다”**를 결과로 남기는 거지. 임베딩 점수만으로 이 대응이 성립한다고 판단하면 안 되고.

### 4. 평가 기준도 ‘풀이 전이’로 잡는 게 좋아

문항 쌍을 보고 팀장에게 이렇게 물어보는 거야.

> **A를 풀고 얻은 핵심 아이디어가 B를 푸는 데 실제로 도움이 되는가? 도움이 된다면 정확히 어느 부분인가?**

그리고 `표현만 비슷함 / 같은 개념이지만 다른 착상 / 착상이 연결됨 / 사실상 같은 문제`를 구분해 평가하면 돼.

내 생각에는 **우리가 목표로 삼을 중심은 ‘같은 개념’보다 ‘핵심 착상의 전이 가능성’**이야. 기존 풀이보고서와 Graph는 그 관계를 설명하고 검증하는 기반으로 쓰고, 벡터는 그런 후보를 놓치지 않고 찾아오는 역할로 두는 게 가장 맞아.
